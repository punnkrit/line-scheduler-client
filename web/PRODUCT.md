# LINE Scheduler

A private tool for one owner to write a LINE message, choose a conversation and send time, and inspect or cancel scheduled messages. The cloud sender must work while the browser and computer are off.

## Interface copy

Use short functional labels. No taglines, promotional headers, decorative subtitles, motivational empty states, or explanatory footers. Remove redundant copy rather than rewriting it. Keep only information needed to select a recipient, compose, choose a time zone, schedule, cancel, or understand delivery and connection failures. Preserve accessible labels.

## Scope

Retain the existing layout and controls. This is a utility, not a marketing page. Never claim a message was sent without a confirmed receipt. Distinguish scheduled, sent, failed, and uncertain outcomes.
